MAGICARD — USDT DEPOSITS

Magicard supports USDT deposits using the TRC20 network.

Customers receive a deposit address for sending USDT.

The customer sends USDT to the provided deposit address using the TRC20 network.

After the transaction is confirmed, the deposit is credited to the customer's Magicard USD wallet.

Customers should always verify the network (TRC20) and deposit address before sending cryptocurrency.

TRC20 is the only supported network for USDT deposits. Do not send funds using any other network.

If a deposit has not appeared after confirmation, the customer should contact Magicard support and provide the transaction hash.

A network funding fee applies to USDT deposits: a flat $1 is deducted, then an additional 1% is deducted from the remainder. For example, sending 100 USDT credits 98.01 USD to the wallet. Deposits of 1 USDT or less do not credit any balance after the fee.

After sending USDT, the customer must submit the transaction hash (TxID) so the deposit can be verified on-chain.

If a USDT deposit failed, the transaction hash (TxID) was rejected, or the deposit has not been credited, the most common reasons are: the transaction has not confirmed on-chain yet (wait a few minutes and submit the hash again); the USDT was not sent on the TRC20 network to the Magicard deposit address, so no matching transfer was found; the transaction hash was copied incorrectly (invalid format) or was already submitted before; or the amount was 1 USDT or less, which credits nothing after the fee. The customer should check these, then try again. If it still fails, contact Magicard support with the transaction hash.
